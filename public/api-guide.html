THÊM VÀ CHỌN API

Thiết lập trong ứng dụng

  1. 01

    Mở Cài đặt kết nối

    Trong DT App, mở biểu tượng cài đặt ở thanh bên rồi tìm mục API cá nhân.

  2. 02

    Chọn nhà cung cấp và dán khóa

    Đặt tên cấu hình để dễ nhớ. Model đã có sẵn; chỉ sửa khi bạn muốn dùng model khác mà tài khoản API hỗ trợ.

  3. 03

    Lưu và chuyển đổi

    Nhấn Lưu API trên thiết bị. Bạn có thể thêm nhiều key từ nhiều tài khoản hoặc nhà cung cấp, sau đó chọn Dùng API này để chuyển.

  4. 04

    Kết nối server và chọn chế độ

    Nhập URL server HTTPS trong Cài đặt kết nối. Bật công tắc API AI nếu muốn gợi ý từ nhà cung cấp; khi tắt, gợi ý tên và mô tả dùng nội dung cục bộ và không gửi API, ảnh hay nội dung tới nhà cung cấp. Xóa nền vẫn chạy U²-Net trên server.

QUYỀN RIÊNG TƯ

Khóa nằm trên thiết bị của bạn

Trên web, API được mã hóa và lưu trong hồ sơ trình duyệt bạn đang dùng. Xóa dữ liệu trang web hoặc đổi trình duyệt sẽ xóa kho đó; các key không đồng bộ sang thiết bị khác.

Trên Windows và macOS, app mã hóa kho API bằng dịch vụ bảo mật của hệ điều hành. API key không được lưu trong Supabase, GitHub Pages hay repository.

Khi dùng tính năng gợi ý, khóa API được gửi qua server bạn đã cấu hình tới nhà cung cấp đã chọn. Chỉ kết nối tới server bạn tin cậy. Tính năng xóa nền dùng server nhưng không dùng API key nhà cung cấp.
